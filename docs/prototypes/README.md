# Miniapp UI Prototype Variants

Generated on 2026-05-06 for the Taro miniapp/mobile UI refresh.

- `miniapp-ui-variant-a-assistant.svg` focuses on a daily assistant home flow.
- `miniapp-ui-variant-b-gallery.svg` focuses on an image-first wardrobe browsing flow.
- `miniapp-ui-variant-c-minimal.svg` focuses on a minimal one-task suggest flow.
- `miniapp-interactive-prototype.html` is a full static interactive prototype based on the approved assistant-style direction.

Notes:
- Pencil MCP was attempted, but the local Pencil desktop bridge was not connected.
- These SVGs are design prototypes, not implementation assets.
